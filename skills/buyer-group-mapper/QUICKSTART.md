# Buyer Group Mapper

A role-to-account map, questions and proof needs, optional contact candidates, and a precise coverage plan.

For optional contact discovery or enrichment, state the account/group scope, missing fields, maximum records, and approved provider credit or money allowance. The skill reuses existing contacts first, checks each operation's cost and access, and records actual usage. Unverified costs or limits leave the route held with a precise manual export request.

## Install or open

In another approved AI tool, attach `SKILL.md` and all reference files in the same conversation or project. No integration is required for the manual path.
